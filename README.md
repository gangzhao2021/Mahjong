# 四川麻将 · 血战到底

1 名真人 + 3 个 AI 的休闲麻将手游。需求见 [PRD](Mahjong%20Mobile%20Game%20V1%20PRD%20and%20Development%20Prompt.md)。

当前进度：**第 1 阶段（核心原型）**。

## 目录结构

```
packages/engine     规则引擎（纯函数、可设种子、按座位视图），PRD 附录 A
packages/ai-play    对局 AI：向听数 + 进张 + 防守 + 牌型价值，三档技术水平
packages/protocol   客户端与服务端之间的 WebSocket 消息类型
apps/server         权威服务端：房间、计时器、托管、断线重连、操作日志
apps/mobile         Expo (React Native) 横屏客户端，也可在浏览器里运行
```

## 运行

需要 Node 22+ 和 pnpm 10+。

```bash
pnpm install
```

启动服务端（ws://localhost:8787，日志写入 `apps/server/data/`）：

```bash
pnpm server
```

在浏览器里运行客户端（最快的试玩方式）：

```bash
pnpm mobile:web
```

在手机或模拟器上运行：先执行 `pnpm mobile`，然后用 Expo Go 扫码。真机需要把服务器地址指向电脑的局域网 IP，例如 `EXPO_PUBLIC_SERVER_URL=ws://192.168.1.20:8787`。

## 第 1 阶段已实现

- 血战到底完整规则：换三张、定缺、碰、直杠/补杠/暗杠、一炮多响、过手胡、抢杠胡、杠上花、杠上炮、呼叫转移、海底捞月、天胡/地胡、查花猪、查大叫、退税、番型表与封顶。所有可变规则都在 `RuleSet` 里。
- 服务端说了算：客户端只收到自己座位的视图。AI 也只看自己的视图，从结构上就没法作弊。
- 每个决定都有计时；连续 2 次超时自动托管；断线或切到后台也转为托管；胡牌后可跳过直接看结算；中途离开照常结算。
- 每手牌都保存为 `{种子, 规则, 操作列表}`，能用 `replayHand` 原样重放。
- 客户端：横屏牌桌、双击或上滑出牌、换三张选牌、定缺建议、碰/杠/胡/过按钮、倒计时、托管提示条、结算面板（含结算明细）。

## 已知限制（按 PRD 留到后续阶段）

- AI 的名字和头像目前是临时占位（`apps/server/src/config.ts`）。第 2 阶段改为固定的 AI 角色名单。
- 只有积分，还没有金币钱包。服务端重启后进行中的牌局会丢失（第 3 阶段接入数据库）。
- 中途离开的牌局由托管打完；如果期间没有重新连接，结果不会在下次打开时展示（第 3 阶段随钱包一起做）。
- 没有音效、动画和教程（第 6 阶段）。
- `app.json` 里的 bundle ID `com.example.mahjong` 是占位，上架前要改。
