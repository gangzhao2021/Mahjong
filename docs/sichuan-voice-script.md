# 四川话真人语音 · 录音台词与规格

给配音员和录音的人用。录好的文件按本文的命名交回，开发时替换掉现在的系统朗读（碰杠胡播报、出牌报牌名、快捷短语）。

## 范围

| 录 | 不录 |
|---|---|
| 碰、杠、胡、自摸等喊牌 | AI 角色的聊天台词：由大模型实时生成，每句都不一样，继续用系统朗读 |
| 出牌报牌名（27 张） | 「听牌」：喊出来等于告诉别人自己听了，正经牌桌上没人喊 |
| 特殊胡法（杠上花、一炮双响……） | 英文界面：继续用系统朗读 |
| 定缺 | |
| 玩家快捷短语（8 句） | |

## 音色

录两套，每套由一位配音员录完全部台词：

- **男声**：三四十岁，嗓门亮、带点豪爽，像茶馆里打牌的老哥。
- **女声**：三四十岁，干脆利落、有点泼辣，像楼下打牌的孃孃。

AI 角色按名字分男女，各用一套；玩家自己用哪套在设置里选。以后想加「老年」「年轻」等音色，照本文再录一套即可。

## 录音要求

- 安静的房间，不要混响，不加任何效果（降噪、压缩、混响都由我们处理）。
- 嘴离话筒距离保持一致，同一套里每句的音量感觉差不多。
- **喊牌类要「喊」出来**，像真的在牌桌上：短、脆、有劲，不拖音。报牌名要快、随意，像顺口一说。
- 每句录 **3 遍**，语气稍有不同（平常 / 更有劲 / 更随意）。游戏里会随机挑一遍播放，避免听起来像复读机。
- 读错、吞字、有杂音的直接重录，不用剪。

## 交付规格

- 格式：WAV，48 kHz，24 bit，单声道（我们再转成游戏用的格式）。
- 每句一个文件，开头留约 0.1 秒静音，结尾不超过 0.3 秒。
- 峰值不超过 −3 dBFS，不要削波。
- 命名：`音色_编号_第几遍.wav`，音色用 `m`（男）或 `f`（女），例如 `m_peng_1.wav`、`f_tile-5s_3.wav`。
- 连同下面的「授权」一起交付。

## 授权

需要配音员签书面授权：同意这些录音用于本游戏（含商业发行、各应用商店、宣传视频），不限期限和地区，以及是否署名。没有书面授权的录音不能上线。

## 台词

「读法」一栏是提示，**以配音员的本地习惯为准**：四川各地叫法略有不同，觉得哪种更地道就怎么读，在交付时备注一下改了哪些。

|---|---|---|
| `peng` | 碰！ | 短促有力 |
| `gang` | 杠！ | 短促有力，用于别人打的牌直接杠 |

## 工作量

每套：喊牌 6 + 特殊胡法 9 + 定缺 3 + 报牌名 27 + 快捷短语 8 = **53 句**，每句 3 遍，共 159 条，在录音棚大约 1 小时。两套共 106 句、318 个文件。

## 交回之后（开发备注）

- 文件放在 `apps/mobile/assets/voice/<音色>/`，转成 AAC（.m4a）单声道 64 kbps 左右，统一响度（约 −16 LUFS）、裁掉多余静音。
- 设置里「语音」多一项：普通话（系统朗读）/ 四川话（真人）。选四川话时，有录音的内容播录音，没有的（AI 聊天、英文界面）仍走系统朗读。
- 喊牌和报牌名沿用现在的规则：报牌名排队太久就跳过，静音键一并静音。
